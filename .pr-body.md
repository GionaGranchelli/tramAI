**feat(persistence): add JDBC suspended invocation store**

Implements JdbcSuspendedInvocationStore in tramai-persistence-jdbc, backed by the existing suspended_invocations table in PostgreSQL. This is the second runtime JDBC store (after JdbcApprovalStore PR #80).

**Scope**
- JdbcSuspendedInvocationStore implementing the existing SuspendedInvocationStore SPI
- JdbcReplayEnvelopeCodec interface + JdbcEncryptedReplayEnvelope data class
- JdbcSuspendedInvocationStoreTest with 22 tests against real PostgreSQL (Testcontainers)
- Requires `api(project(":tramai-engine"))` for SPI types

**Non-goals**
- No JdbcAuditStore
- No JdbcAuditOutboxStore
- No worker lease implementation
- No Spring Boot autoconfiguration
- No Flyway/Liquibase integration
- No HikariCP runtime wiring
- No production key-management integration
- No release workflow changes
- No public stable 1.0 API claim

**Key design decisions**

1. **Explicit DTO serialization (no Jackson default typing)**: Messages and tool calls are serialized via PersistedMessage/PersistedToolCall DTOs instead of Jackson polymorphic typing. This removes the security risk of broad type metadata in persistent JSON.

2. **Replay envelope invariant validation**: Before persistence, the store validates that the tool call ID, name, and index in the messages match the metadata. This catches misconfigured codecs or callers.

3. **Atomic remove with FOR UPDATE**: remove() reads and deletes inside one explicit transaction with SELECT ... FOR UPDATE, preventing concurrent double-consumption. Decryption failure triggers rollback for fail-closed recovery.

4. **Constraint name detection**: Uses regex extraction of PostgreSQL constraint names from error message text (e.g., "uq_suspended_invocations_replay_envelope_digest") to reliably distinguish PK vs. digest violations without message-text hacking.

5. **Digest validation via regex**: validateDigestField uses ^sha256:[0-9a-f]{64}$ regex instead of length+prefix checks.

6. **Encryption metadata**: All encryption fields (keyId, algorithm, nonce, payloadDigest) populated and non-nullable. Stored in encrypted form only. Codec injected by caller — no key management inside the store.

7. **Sanitized persistence**: No raw tool arguments, prompts, model responses, or sensitive payloads in plaintext. Only digest, service_key, operation_key, descriptor_hash are stored in plaintext indexed columns.

**Schema tables used**
- `suspended_invocations` (from V1__sovereign_persistence.sql)
