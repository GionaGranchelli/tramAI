# TramAI 0.7.0 Roadmap

> **Status:** Active roadmap. 0.6.x is frozen except for bug and security fixes.

## Purpose

0.7.0 is the next feature train after the 0.6.0 quality, architecture, and maintainability release. It should extend the existing governed-workflow runtime without weakening its authority, compatibility, or evidence boundaries.

## Priorities

- Improve adoption from the published artifacts and keep external consumer paths documented.
- Advance deferred 0.6.x characterization and reliability work where evidence shows a real user or operator need.
- Extend provider, persistence, and workflow contracts through the existing TCK and architecture-governance mechanisms.
- Continue sovereign-runtime hardening, while keeping production certification and compliance claims explicitly scoped.
- Preserve binary compatibility and document any intentional migration before changing stable APIs.

## Release policy

- No new features are backported to 0.6.x.
- Bug and security fixes may be released as 0.6.1, 0.6.2, and so on, with focused verification and no baseline or policy weakening.
- New features target 0.7.0 and must be represented by a roadmap item before implementation.
- The 0.6.0 release notes and migration guide remain the source of truth for the released 0.6.x contract.

## Non-goals

- No stable 1.0 API claim.
- No compliance or cloud-provider production-certification claim without separate evidence.
- No replacement governance, approval, persistence, or evidence authority alongside TramAI.
