# ADR-005: Keep the Core Framework-Agnostic and Ship Adapters Separately

- Status: accepted
- Date: 2026-04-17

## Context

Tramai is intended to work in Spring, Quarkus, Micronaut, and plain JVM applications. The design rejects a Spring-centric product architecture even though Spring support is important for adoption.

## Decision

Tramai will keep the core runtime framework-agnostic.

Framework support will be delivered as thin adapter modules, starting with `tramai-spring`. The standalone runtime remains the canonical execution model, and framework adapters wire that runtime into dependency injection and configuration systems.

## Consequences

Positive:

- broader JVM applicability
- clearer module boundaries
- less risk of framework assumptions leaking into the core

Negative:

- adapter modules need active maintenance
- some framework conveniences must be implemented separately
