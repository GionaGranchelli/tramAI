## Characterization Legend

- **Characterized:** Behaviour has tests that prove the contract, not just execute code.
- **Partially characterized:** Some paths tested, but not all failure modes or boundary conditions.
- **Uncharacterized:** No test proves the behaviour; tests may exist but don't assert semantic correctness.
- **Not applicable:** Behaviour does not exist in this module or version.

## Update Process

1. Run characterization tests for a behaviour family.
2. Update the corresponding row with test class names and coverage status.
3. If gaps are found, create a characterization task in the relevant 0.6.x epic.
4. Re-run before each refactoring PR to confirm no regression.
