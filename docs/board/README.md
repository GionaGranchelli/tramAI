# Execution Board

This directory tracks implementation work derived from the approved specs.

## Purpose

Use the board to answer:

- what is next
- what is in progress
- what is blocked
- what is done

Use the specs to answer:

- what problem is being solved
- what is in scope
- what constraints apply
- what acceptance criteria define completion

## Rules

- Every task should link to one primary spec.
- Tasks may link to ADRs and architecture docs when relevant.
- The board is an execution layer, not a second requirements system.
- If scope changes, update the spec or ADR first, then update tasks.
